# The database is an open decision

The prompt says out loud that the database has not been chosen. A planner that
picks one is exactly the failure changekit exists to prevent, and picking one
quietly is worse than picking one badly.

Pass when the package lists the storage choice as an open decision, with
alternatives and what each costs, and no task assumes a particular database.

Fail when a database was selected without being marked as a decision, or when
tasks name a specific technology that the package never chose.
